KEY INNOVATIONS

🐋 Smart Money Tracking

Erkennung institutioneller Aktivitäten durch OBV, MFI, A/D Line und Volume Spikes.

Der Bot erkennt "Whale"-Bewegungen bevor der Preis reagiert - durch Volumen-Divergenzen und Order-Flow-Signale.

⏰ Cyclical Time Encoding

Sin/Cos-Transformation projiziert Zeit auf einen Kreis für zyklische Muster-Erkennung.

Markt-Öffnungszeiten, Wochenend-Liquidität und zyklische Wiederholungen werden korrekt interpretiert.

🔱 Dueling Architecture

Trennung von State Value ("Wie gefährlich?") und Action Advantage ("Was ist besser?").

Ermöglicht schnelleres Lernen von Risikovermeidung in Bärenmärkten.
