================================================================================
ENHANCED DQN TRADING BOT - INSTALLATION & QUICK START GUIDE
================================================================================

 TOTAL TIME: 5 Minutes Setup + 2-4 Hours Training

================================================================================
STEP 1: SYSTEM REQUIREMENTS
================================================================================

 Python 3.8 or higher
 8GB RAM minimum (16GB recommended)
 GPU optional (but speeds up training 3-5x)
 Internet connection (for data download)

================================================================================
STEP 2: INSTALL DEPENDENCIES
================================================================================

Open terminal/command prompt and run:

pip install torch numpy pandas yfinance scikit-learn tqdm

OR if you have a requirements.txt:

pip install -r requirements.txt

================================================================================
STEP 3: EXTRACT FILES
================================================================================

Extract the Enhanced_DQN_Fixed folder to your desired location.

Your folder structure should look like:

Enhanced_DQN_Fixed/
├── train_enhanced_dqn.py
├── agents/
├── env/
├── utils/
├── models/
└── logs/

================================================================================
STEP 4: VERIFY INSTALLATION
================================================================================

Navigate to the Enhanced_DQN_Fixed folder:

cd Enhanced_DQN_Fixed

Test import:

python -c "from utils.indicators import TechnicalIndicators; print(' Imports working!')"

If you see " Imports working!" - you're ready!

================================================================================
STEP 5: RUN TRAINING (DEFAULT SETTINGS)
================================================================================

Simply run:

python train_enhanced_dqn.py

This will:
- Download BTC-USD data from 2020-2024
- Add 42 technical features
- Train for 50 episodes (~2-4 hours)
- Evaluate and compare against benchmarks
- Save best model to models/best_model.pth

================================================================================
STEP 6: CUSTOMIZE (OPTIONAL)
================================================================================

Edit train_enhanced_dqn.py to change:

1. SYMBOL:
   "symbol": "BTC-USD"    "ETH-USD", "AAPL", etc.

2. TIME PERIOD:
   "start_date": "2020-01-01"    "2018-01-01"
   "end_date": "2024-01-01"      "2024-12-31"

3. INTERVAL:
   "interval": "1h"    "15m", "5m", "1d"

4. EPISODES:
   "episodes": 50    100, 200 (more = better but slower)

5. CAPITAL:
   "initial_cash": 10000.0    Any amount

================================================================================
STEP 7: MONITOR TRAINING
================================================================================

During training you'll see:

Episode 10/50: Portfolio=$11,234.56 | Reward=0.0234 | Trades=15
  ε: 0.850 | Portfolio: $11,235 | Trades: 15

This means:
- ε (epsilon): Exploration rate (decreases over time)
- Portfolio: Current portfolio value
- Trades: Number of trades executed

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "No module named 'torch'"
SOLUTION: pip install torch

PROBLEM: "No module named 'yfinance'"
SOLUTION: pip install yfinance

PROBLEM: "Import Error: No module named 'agents'"
SOLUTION: Make sure you're in the Enhanced_DQN_Fixed folder
         cd Enhanced_DQN_Fixed

PROBLEM: "CUDA out of memory"
SOLUTION: Edit train_enhanced_dqn.py, change "batch_size": 64 to 32

PROBLEM: "Not enough data downloaded"
SOLUTION: - Check internet connection
         - Try different symbol
         - Increase start_date to get more history

PROBLEM: Training is very slow
SOLUTION: - Normal! 50 episodes takes 2-4 hours on CPU
         - Use GPU if available (3-5x faster)
         - Reduce episodes to 20 for quick test

================================================================================
ADVANCED: USING TRAINED MODEL
================================================================================

To use your trained model for predictions:

```python
from agents.dqn_agent import Agent
from env.trading_env import TradingEnvironment
import torch

# Load model
agent = Agent(state_size=42, action_size=3, window_size=24)
checkpoint = torch.load('models/best_model.pth')
agent.policy_net.load_state_dict(checkpoint['model_state_dict'])
agent.is_eval = True

# Create environment with new data
env = TradingEnvironment(df=new_data, ...)

# Make predictions
state, info = env.reset()
action = agent.act(state, action_mask=info['action_mask'])
```
